# Gestor de Subconjunto

Protótipo web para demonstração da montagem de escalas de uma linha de subconjunto.

## Funcionalidades

- Escala por postos 20, 30, 40, 50, 60 e 70
- Regras de pessoas fixas e restritas
- Rodízio de Preckoff por hora
- Exportação para PDF pelo navegador
- Tela ao vivo para TV com vídeo, produto, FP demonstrativa, horários e pessoas por posto

## Executar localmente

```bash
npm install
npm test
npm start
```

Acesse `http://localhost:3000`.

> Dados e produtos são demonstrativos. A validação operacional deve ser feita pela empresa antes de qualquer uso real.
