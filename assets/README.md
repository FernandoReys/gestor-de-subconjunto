# Mídias da linha

Este diretório contém a imagem de prévia usada pelo protótipo.

Para executar a experiência completa localmente, mantenha também estes arquivos neste diretório:

- `linha-3d.png` — ilustração da linha
- `linha-producao.mp4` — vídeo em loop usado na abertura e na tela de TV

Eles foram mantidos fora deste repositório para evitar que mídia operacional de grande porte seja versionada como código. A publicação privada do protótipo contém as mídias completas.
