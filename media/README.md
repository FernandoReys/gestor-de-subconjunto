# Materiais de vídeo e imagem

Arquivos originais da apresentação. Eles ficam versionados para edição e referência, mas não entram no build porque a interface atual não os usa. Se um vídeo voltar à interface, mova a versão otimizada para `public/assets/` e referencie seu caminho no cliente.

`public/assets/linha-poster.jpg` é a imagem usada hoje na abertura e é copiada para `dist/assets/` pelo build.
